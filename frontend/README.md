# Delve Frontend — Research UI

React 19 single-page application for autonomous academic research, live deliberation streaming, and manuscript viewing.

---

## Tech Stack
- **Framework:** React 19, TypeScript, Vite
- **Styling:** CSS Design Tokens, Academic Layouts
- **Animations:** Framer Motion
- **Icons:** Lucide Icons
- **Markdown & PDF:** React Markdown, Remark GFM, KaTeX

---

## Setup & Local Run

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env

# 3. Start development server
npm run dev
```

---

## Deployment (Vercel)
Configured for zero-config Vercel deployment with `vercel.json` including security headers and SPA rewrites.
